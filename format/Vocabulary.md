# 어휘(형식 1판)

기계판은 [resources/vocabulary.json](../resources/vocabulary.json) 한 파일이다. 이 문서의 표는 그 파일을 사람이 읽게 옮긴 것이다. 둘이 다르면 JSON 이 맞다.

- 머리글에는 **코드**(영어)를 쓰고, 본문의 관계 줄과 화면에는 **이름**(한국어)을 쓴다. 읽을 때는 둘 다 받는다.
- 모르는 코드는 버리지 않고 그대로 보관한다. 화면에는 이름 대신 코드를 보인다. 다시 쓸 때도 그 글자 그대로 쓴다.

## 1. 개념 종류

개념 파일 머리글 `kind` 의 값이다.

| 코드 | 이름 | 뜻 | 예 |
| --- | --- | --- | --- |
| `method` | 방법 | 알고리즘 · 모델 · 기법 · 절차 | Faster R-CNN, 이분 탐색 |
| `component` | 구성요소 | 방법이나 시스템을 이루는 부품 | RPN, Focal Loss, 결제 모듈 |
| `task` | 문제 | 풀려는 과제 | 객체 검출, 기계 번역 |
| `data` | 데이터 | 데이터셋 · 벤치마크 · 자료 | COCO, VOC 2007 |
| `metric` | 지표 | 평가 기준 | mAP, BLEU, 응답 시간 |
| `system` | 시스템 | 제품 · 서비스 · 도구(기획서에 많음) | 결제 서비스 |
| `idea` | 원리 | 위에 들지 않는 원리 · 이론 · 현상 | 어텐션, 클래스 불균형 |

## 2. 관계 종류

관계 줄의 `**<관계 이름>**` 자리에 이름으로, 기록에는 코드로 둔다.

| 코드 | 이름 | 방향(from → to) | 뜻 | 예 |
| --- | --- | --- | --- | --- |
| `improves` | 개선 | 새것 → 옛것 | from 이 to 의 한계를 고쳤다 | Fast R-CNN → R-CNN |
| `uses` | 사용 | 전체 → 부품 | from 이 to 를 쓰거나 포함한다 | Faster R-CNN → RPN |
| `isA` | 종류 | 하위 → 상위 | from 은 to 의 한 종류다 | YOLO → 1단계 검출기 |
| `solves` | 해결 | 방법 → 문제 | from 이 to 를 푼다 | YOLO → 객체 검출 |
| `alternative` | 대안 | 방향 없음(↔) | 같은 문제를 다르게 푼다 | YOLO ↔ Faster R-CNN |

- 다섯으로 시작한다. 종류가 많으면 아무도 고르지 않는다.
- 계열 · 분류(예: "1단계 검출기")는 따로 칸을 두지 않고 `isA` 관계로 나타낸다. 분류 트리 · 타임라인의 갈래는 이 관계에서 나온다.
- 방향 없는 종류는 JSON 에 `"undirected": true` 로 적는다. 화살표(`↔`)와 같은 관계 판정(A ↔ B = B ↔ A)이 이 값을 따른다.

## 3. 표 열 종류

| 코드 | 이름 | 정하는 법 |
| --- | --- | --- |
| `quantity` | 수치 | 빈 칸을 뺀 모든 칸이 숫자 |
| `ordinal` | 순서 | 주석 `ordered` 에 그 열 이름이 있다 |
| `nominal` | 범주 | 나머지 |

자세한 판별은 [DataTable.md §4](DataTable.md#4-열-종류--읽을-때-정한다).

## 4. 상태

| 코드 | 이름 | 뜻 |
| --- | --- | --- |
| `confirmed` | 확인됨 | 사람이 적었거나 확인했다. `상태` 줄이 없으면 이것 |
| `proposed` | AI 제안 | AI 가 뽑았고 아직 확인하지 않았다 |

## 5. 판

| 판 | 뜻 | 올리는 때 | 판이 높은 파일 |
| --- | --- | --- | --- |
| `format` | 파일 문법과 어휘의 판. 1부터 | 문법이나 어휘가 바뀔 때(종류를 더하기만 해도) | 아는 것만 읽고 다시 쓰지 않는다(읽기 전용) |
| `rules` | 추출 규칙(AI 지침 · 스키마)의 판 | 지침을 고칠 때 | 영향 없음. 판이 낮은 문서는 다시 분석하면 새 규칙으로 뽑힌다 |

- 두 판 모두 `vocabulary.json` 에 적고, 코드는 그 값을 읽는다.
- `rules` 는 Ocean 의 추출 규칙 판이다. 라이브러리는 머리글 값을 읽고 쓰기만 한다.

## 6. `vocabulary.json` 모양

```json
{
  "format": 1,
  "rules": 1,
  "conceptKinds":  [ { "code": "method", "label": "방법", "meaning": "…", "examples": "…" } ],
  "relationKinds": [ { "code": "alternative", "label": "대안", "direction": "방향 없음(↔)", "meaning": "…", "examples": "…", "undirected": true } ],
  "statuses":      [ { "code": "confirmed", "label": "확인됨" } ],
  "columnKinds":   [ { "code": "quantity", "label": "수치" } ]
}
```

- 이 한 파일에서 AI 스키마의 `enum`, 지침의 어휘 절, 검사기, 화면 이름표가 나온다(Ocean).
- 파일이 없거나 깨졌으면 경고를 남기고 `format` 을 `0` 으로 읽는다.
