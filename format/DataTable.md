# 데이터 표 — 지식 안의 차트

문서 파일의 `## 데이터` 절에 둔다. 다른 편집기에서는 제목과 보통 표로 보이고, 주석 한 줄이 차트로 그릴 열을 알려 준다.

```markdown
## 데이터

### YOLO 에서 YOLOv2 까지 — 하나씩 더한 개선

<!-- ocean:data x="단계" y="mAP" ordered="단계" cumulative="yes" concepts="yolov2,yolo" condition="VOC 2007 test" where="표 2" -->

| 단계 | mAP (%) |
| --- | --: |
| YOLO (기준) | 63.4 |
| + 배치 정규화 | 65.8 |
```

## 1. 블록

- 표 하나 = `### <제목>` 블록 하나다. 블록은 다음 `### ` 줄 앞까지다.
- Ocean 이 쓰는 모양: `### 제목` → 빈 줄 → `ocean:data` 주석 한 줄 → 빈 줄 → GFM 표. 표 사이는 빈 줄 하나다.
- 주석은 표 **앞**에 둔다. 표가 끝난 뒤(빈 줄 뒤)에 둔 주석은 읽지 않는다.
- 주석도 표도 없는 `###` 블록은 표가 아니다. `###` 줄을 포함한 그 줄들은 읽지 못한 줄로 그대로 남는다([DocumentFile.md §7](DocumentFile.md#7-읽지-못한-줄)).
- `## 데이터` 안에서 `###` 블록 밖의 줄도 읽지 못한 줄이다.

## 2. `ocean:data` 주석

```
<!-- ocean:data 이름="값" 이름="값" … -->
```

| 속성 | 값 | 뜻 |
| --- | --- | --- |
| `x` | 열 이름 하나 | 기준 열(가로축이 될 것) |
| `y` | 열 이름, 쉼표로 여럿 | 비교할 수치 열들 |
| `series` | 열 이름 하나 | 계열로 나눌 열 |
| `ordered` | 열 이름, 쉼표로 여럿 | 순서가 뜻이 있는 열(단계, 크기 S/M/L, 입력 크기). 숫자 열이어도 순서로 본다(§4) |
| `cumulative` | `yes` | 앞 행에 하나씩 더해 가는 단계 표(누적 ablation) |
| `concepts` | 개념 id, 쉼표로 여럿 | 이 표가 다루는 개념. 지식 사이 보기에서 표를 개념에 붙일 때 쓴다 |
| `condition` | 글 | 측정 조건(데이터셋 · 설정 · 하드웨어). 각주의 뜻도 여기에 |
| `where` | 글 | 원문 속 자리("표 2" · "그림 4") |

- 열 이름은 머리 칸에서 단위를 뺀 이름이다(`mAP (%)` 의 열 이름은 `mAP`).
- `x` · `y` 는 늘 쓴다(비어도 `x=""`). 나머지는 값이 있을 때만 쓴다. Ocean 은 위 표의 순서로 쓰고, 읽을 때는 순서를 보지 않는다.
- `cumulative` 는 값이 `yes` 일 때만 참이다.
- 값의 `&` · `"` · `>` 는 `&amp;` · `&quot;` · `&gt;` 로 쓰고 읽을 때 되돌린다. 값에 `-->` 가 있어도 주석이 닫히지 않는다. 줄바꿈은 공백 하나로 쓴다.
- **모르는 속성은 읽지 않고, 다시 쓰면 사라진다**(`## 데이터` 는 정해진 절이라 통째로 다시 쓴다). 보기 정보(색 · 차트 종류)를 여기에 넣지 않는다.

## 3. 표

- GFM 표다. 머리 줄 바로 다음 줄이 **같은 칸 수의 구분 줄**일 때만 표가 시작된다. 구분 줄의 칸은 `:?-+:?` 꼴이다.
- 표 줄은 앞에 공백 세 칸까지 둘 수 있고, 바깥 `|` 는 없어도 된다. `\|` 는 칸 구분이 아니라 칸 안의 `|` 다.
- 머리 칸 `이름 (단위)`: 끝의 ` (…)`(앞에 공백, 괄호 안에 괄호 없음)가 단위다. 괄호가 없으면 단위가 없다. `f(x)` 처럼 앞에 공백이 없으면 이름 그대로다.
- 행의 칸 수가 머리 칸 수와 다르면 그 행은 읽지 못한 줄이다(표는 남는다).
- 표는 머리 줄을 본 뒤 첫 빈 줄에서 끝난다(GFM 과 같다). 그 뒤 다음 `### ` 까지의 줄은 읽지 못한 줄이다.
- 칸은 글자다. 앞뒤 공백은 빼고 이어진 공백은 하나로 접는다.
- Ocean 이 쓰는 모양: `| a | b |`, 구분 줄은 수치 열 `--:` · 나머지 `---`, 칸 안의 `|` 는 `\|`.

## 4. 열 종류 — 읽을 때 정한다

파일에 적지 않는다. 칸 글자와 `ordered` 로 읽을 때마다 정한다.

1. `ordered` 에 있으면 **순서**(`ordinal`). 숫자 열이어도 그렇다.
2. 빈 칸을 뺀 모든 칸이 숫자면 **수치**(`quantity`).
3. 나머지는 **범주**(`nominal`). 칸이 하나도 없는 열도 범주다.

숫자로 보는 꼴: 앞뒤 공백, 부호(`+` · `-`), 천 단위 쉼표(`1,000`), 소수(`63.4`), 지수(`1e-3`).

| 칸 | 숫자인가 |
| --- | --- |
| `63.4` · `-2` · `1,000.5` · `1e-3` | 예 |
| (빈 칸) | 셈에서 뺀다 |
| `63.4±0.2` · `12%` · `.5` · `1 000` · `-` · `—` · `N/A` | 아니오 |

- **값이 없는 칸은 비워 둔다.** `-` · `—` 를 쓰면 그 열 전체가 범주가 된다.
- 단위는 칸이 아니라 머리 칸에 둔다(`12%` 가 아니라 머리 칸 `(%)` 에 칸 `12`).

## 5. 이름 제약

- 열 이름에 쉼표를 쓰지 않는다(`y` · `ordered` 는 쉼표에서 나뉜다). Ocean 은 AI 가 준 쉼표를 ` · ` 로 바꿔 쓴다.
- 열 이름 끝에 ` (…)` 를 쓰지 않는다(단위로 읽힌다). 단위에는 괄호를 쓰지 않는다.
- 열 이름은 표 안에서 겹치지 않게 한다. Ocean 은 겹치면 뒤의 것에 ` 2`, ` 3` … 을 붙인다.
- `x` · `y` · `series` · `ordered` 의 이름은 열 이름과 글자가 같아야 한다.

## 6. 예

계열이 있는 표. 검출기마다 점을 나눠 FPS–mAP 로 그릴 수 있다.

```markdown
### 속도와 정확도 — 입력 크기별

<!-- ocean:data x="FPS" y="mAP" series="검출기" concepts="yolov2" condition="VOC 2007 test · GTX Titan X" where="표 3" -->

| 검출기 | 입력 크기 (px) | mAP (%) | FPS |
| --- | --: | --: | --: |
| SSD | 300 | 74.3 | 46 |
| SSD | 500 | 76.8 | 19 |
| YOLOv2 | 288 | 69.0 | 91 |
| YOLOv2 | 544 | 78.6 | 40 |
```

숫자 열을 순서로 보는 표. `입력 크기` 가 `ordered` 에 있어 순서 열이 되고, 구분 줄이 `---` 다.

```markdown
### 입력 크기별 정확도

<!-- ocean:data x="입력 크기" y="mAP,FPS" ordered="입력 크기" concepts="yolov2" -->

| 입력 크기 (px) | mAP (%) | FPS |
| --- | --: | --: |
| 288 | 69.0 | 91 |
| 416 | 76.8 | 67 |
| 544 | 78.6 | 40 |
```
