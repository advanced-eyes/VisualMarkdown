# 관계 — 그래프의 선

관계는 두 개념을 잇는 선이다. 문서 파일과 개념 파일의 `## 관계` 절에 같은 문법으로 쓴다.

```markdown
## 관계

- [YOLOv2](../concepts/yolov2.md) **개선** → [YOLO](../concepts/yolo.md)
  - 설명: 배치 정규화 · anchor · 고해상도 학습으로 mAP 63.4 → 76.8, 속도 유지
  - 위치: 2절
  - 인용: "At 67 FPS, YOLOv2 gets 76.8 mAP on VOC 2007."
  - 상태: AI 제안
- [YOLOv2](../concepts/yolov2.md) **대안** ↔ [Faster R-CNN](../concepts/faster-r-cnn.md)
```

## 1. 첫 줄

```
- <from 링크> **<관계 이름>** <화살표> <to 링크>
```

- 줄 전체가 이 꼴이어야 한다. 앞뒤에 다른 글이 붙으면 읽지 못한 줄이다.
- 링크 두 개 모두 표준 마크다운 링크여야 한다([Folder.md §4](Folder.md#4-링크)).
- 관계 이름은 어휘의 이름(`개선` · `사용` · `종류` · `해결` · `대안`)이나 코드(`improves` …)다. Ocean 은 이름으로 쓴다. 어휘에 없는 이름은 그대로 종류 코드로 보관한다([Vocabulary.md §2](Vocabulary.md#2-관계-종류)).
- 화살표는 `→`(방향 있음)이나 `↔`(방향 없음)다. **방향은 화살표가 아니라 종류가 정한다.** 읽을 때 화살표는 보지 않고, 쓸 때 종류에 맞는 화살표를 쓴다(`대안` 만 `↔`).
- 방향 있는 종류는 어휘 표의 방향을 따른다. 개선은 새것 → 옛것, 사용은 전체 → 부품, 종류는 하위 → 상위, 해결은 방법 → 문제다.
- `대안` 은 한 번만 적는다. from 은 그 문서가 주로 다루는 쪽이다.

## 2. 하위 항목

| 키 | 값 |
| --- | --- |
| `설명` | 한 문장. 개선이면 무엇을 고쳤는지 숫자와 함께 |
| `위치` | 원문 속 자리("2절" · "5쪽" · "표 3") |
| `인용` | 관계를 뒷받침하는 원문 한 구절(원문 언어 그대로). 앞뒤를 감싼 `"` 는 벗겨 읽고, 쓸 때 감싼다 |
| `상태` | `AI 제안` 이면 아직 사람이 확인하지 않았다(§3) |

- 하위 항목 공통 규칙(들여쓰기 · 모르는 하위 항목 보존 · 바로 앞 항목에만 붙음)은 [DocumentFile.md §6](DocumentFile.md#6-하위-항목--카드와-관계에-같다).

## 3. 상태

| `상태` 줄 | 읽는 값 |
| --- | --- |
| 없음 | 확인됨 |
| `확인됨` · `confirmed` | 확인됨 |
| `AI 제안` · `proposed` | AI 제안 |
| 그 밖의 값 | AI 제안(확인 안 된 쪽으로 안전하게) |

- 확인됨이면 Ocean 은 `상태` 줄을 쓰지 않는다. 그래서 손으로 적은 관계는 저절로 확인됨이다.
- 보기는 상태로 선 모양을 나눌 수 있다(예: AI 제안은 점선). 정한 것은 아니다.

## 4. 어디에 적나

| 자리 | 뜻 | 다시 저장할 때 |
| --- | --- | --- |
| 문서 파일 `## 관계` | 그 문서가 말한 관계. 출처가 그 문서다 | 새 분석 결과로 바뀐다. 같은 (from · 종류 · to) 의 옛 관계에서 상태와 모르는 하위 항목을 이어 받는다. 새 분석에 없는 옛 관계는 확인됨이면 남고, AI 제안이면 버린다 |
| 개념 파일 `## 관계` | 사람이 직접 적은, 문서에 매이지 않은 관계 | 라이브러리가 고치지 않는다 |

- 관계를 손으로 더할 때는 개념 파일에 적기를 권한다. 문서 파일에 적어도 확인됨이라 다시 저장 때 남는다.
- 링크 경로는 문서 파일에서 `../concepts/<id>.md`, 개념 파일에서 `<id>.md` 다.

## 5. 같은 관계

- (from · 종류 · to) 가 같으면 같은 관계다. 방향 없는 종류는 from · to 를 바꿔 적어도(A ↔ B, B ↔ A) 같다.
- 여러 파일이 같은 관계를 말하면 그래프에서는 선 하나로 합친다. 합치는 법은 [Visualization.md §2](Visualization.md#2-색인--파일에서-그래프로). 파일에는 적은 그대로 남는다.
