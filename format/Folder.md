# 폴더와 파일 이름

## 1. 폴더

```
<root>/wiki/documents/<문서 파일 이름>.md   문서 하나에서 뽑은 지식: 차례 · 핵심 숫자 · 카드 · 관계 · 데이터 표
<root>/wiki/concepts/<개념 id>.md           개념 하나: 이름 · 별칭 · 종류 · 연도 · 정의 · 손으로 적은 관계
```

- `wiki/` 는 그대로 Obsidian 볼트나 VS Code 폴더로 열 수 있다. 다른 파일(`.obsidian/`, 그림)이 있어도 된다. 라이브러리는 두 폴더 바로 아래의 `*.md` 만 읽는다.
- 한 문서에서 뽑은 것(카드 · 관계 · 표)은 그 문서 파일에만 있다. 문서를 다시 저장하면 그 파일 하나만 바뀌고, 지우면 그 파일만 지운다.
- 개념 파일은 여러 문서가 함께 가리키는 점이다. 신원(이름 · 별칭 · 종류 · 연도 · 정의)만 갖는다([ConceptFile.md](ConceptFile.md)).

## 2. 개념 id

개념 id 는 처음 만들 때 이름에서 만든다. 한 번 정하면 바뀌지 않는다(나중에 이름을 바꿔도 파일 이름은 그대로).

1. NFC 정규화하고 소문자로 바꾼다.
2. 공백(이어진 공백은 하나로)을 `-` 로 바꾼다.
3. 다음 글자를 뺀다: 파일 이름에 못 쓰는 글자 `\ / : * ? " < > |`, `# [ ] ( )`, 쉼표 `,`, `%`, 제어 문자.
4. 겹친 `-` 는 하나로, 앞뒤 `-` 는 뺀다.
5. 60자까지 자르고, 앞뒤 `-` 를 다시 뺀다.
6. 비면 `concept`.
7. Windows 예약 이름(`con` · `prn` · `aux` · `nul` · `com1`–`com9` · `lpt1`–`lpt9`)이면 `-1` 을 붙인다.
8. 이미 있으면 `-2`, `-3` … 을 붙인다.

- 쉼표를 빼는 것은 `ocean:data` 주석의 `concepts` 가 개념 id 를 쉼표로 잇기 때문이다. `%` 를 빼는 것은 링크 경로의 퍼센트 부호화(`%XX`)와 겹치지 않게 하려는 것이다.
- 한국어는 그대로 둔다.

| 이름 | id |
| --- | --- |
| YOLOv2 | `yolov2` |
| Faster R-CNN | `faster-r-cnn` |
| 1단계 검출기 | `1단계-검출기` |
| 50% rule | `50-rule` |
| CON | `con-1` |
| `[ ]` | `concept` |

**개념의 id 는 파일 이름(확장자 뺀 것)이다.** 링크 대상이 파일 이름이기 때문이다. 머리글 `id` 가 파일 이름과 다르면 경고를 남기고 파일 이름을 id 로 쓴다. 그 파일을 다시 쓸 때 머리글을 `id: <파일 이름>` 으로 고친다.

## 3. 문서 파일 이름

- 문서 제목으로 §2 의 규칙을 쓴다. 비면 `document`. 예: `YOLO9000: Better, Faster, Stronger` → `yolo9000-better-faster-stronger.md`.
- 문서의 진짜 id 는 머리글 `id`(UUID)다. 다시 저장할 때 파일은 이 id 로 찾는다. 제목이 바뀌어도 파일 이름은 그대로다.

## 4. 링크

표준 마크다운 링크와 상대 경로를 쓴다. 다른 편집기에서 눌러 옮겨 갈 수 있다.

| 어디서 → 어디로 | 모양 |
| --- | --- |
| 문서 → 개념 | `[YOLOv2](../concepts/yolov2.md)` |
| 개념 → 개념 | `[1단계 검출기](1단계-검출기.md)` |

쓸 때
- 경로는 글자 그대로 쓴다. 한국어도 퍼센트 인코딩하지 않는다.
- 링크 글자의 `\` `[` `]` 앞에 `\` 를 붙인다.

읽을 때
- 개념 id 는 경로의 마지막 `/` 뒤에서 `.md`(대소문자 무관)를 뺀 것이다. 폴더 부분은 보지 않는다.
- `%XX` 는 되돌린다. 다른 편집기가 쓴 `1%EB%8B%A8%EA%B3%84-%EA%B2%80%EC%B6%9C%EA%B8%B0.md` 도 `1단계-검출기` 다. 올바른 `%XX` 가 아닌 `%` 는 그대로 둔다. 되돌린 글이 UTF-8 이 아니거나 제어 문자가 생기면 원래 경로를 쓴다.
- 링크 글자의 `\x` 는 `x` 로 되돌리고, 이어진 공백은 하나로 접는다.
- 링크가 가리키는 개념 파일이 없으면 그 관계 · 연결은 그래프에 넣지 않는다([Visualization.md](Visualization.md)).
- Obsidian 위키 링크(`[[YOLO]]`)는 읽지 않는다.
